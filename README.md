# Расшифровки выступлений спикеров — Yagla / Vitamin.tools

База знаний: текстовые расшифровки **выступлений спикеров** с YouTube-канала
[@YaglaRuOnline](https://www.youtube.com/@YaglaRuOnline). Нужна, чтобы автоматически
обогащать статьи и материалы экспертизой из докладов (а не держать её мёртвым грузом в видео).

## Что внутри

- `transcripts/<категория>/<дата>__<тема>.txt` — по одной расшифровке на выступление.
  У каждого файла шапка: тема, спикер, должность, дата, категория, длительность, ссылка на YouTube.
- `INDEX.md` — оглавление: все выступления, сгруппированы по категориям, с датой, спикером и ссылками.

## Правила отбора

- **Только 2024+** — доклады, записанные раньше 2024 года, не берём.
- **Только ≤ 60 минут** — длинные вебинары/эфиры отсекаем.
- **Без «протухших» инфоповодов** — исключены доклады 2024 года про платную рекламу/трафик
  (контекст, РСЯ, VK-таргет, посевы, Telegram Ads), где механика площадок с тех пор изменилась.
  По AI/нейросетям планка ещё строже (тема устаревает быстрее всего).

## Как собрано

Тексты взяты из **автоматических субтитров YouTube без скачивания видео**
(`yt-dlp --skip-download --write-auto-subs`, формат `json3`, дорожка `ru-orig`).
Это ASR-расшифровка русской речи: возможны слова-паразитические вставки и неточности
пунктуации — но содержание докладов передано полностью.

Пайплайн-скрипты лежат в `pipeline/` (классификация + сбор + сборка `.txt`).

## Как использовать

Чтобы найти релевантную экспертизу под статью — ищите по `INDEX.md` (категория + тема + спикер)
или грепом по ключевым словам в `transcripts/`. Открывайте нужный `.txt`, читайте содержание,
вплетайте в материал факты, цифры, тезисы и примеры спикера.
